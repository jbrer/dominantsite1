# ДОМИНАНТ — сайт-витрина магазина стройматериалов

Сайт для магазина «ДОМИНАНТ» (г. Дрогичин, ул. Ленина 2А): двери, плитка,
ламинат, кухни. Доставка по Брестской области (Пинск — Иваново — Дрогичин).

Витрина товаров с фильтрами, корзина, заявки (имя + телефон, без онлайн-оплаты)
и мини-админка для управления товарами и заявками.

## Стек

- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS 4 + shadcn/ui
- Prisma 6 + SQLite (`db/custom.db`)
- zustand (корзина с сохранением в localStorage), framer-motion

## Быстрый старт

```bash
# 1) зависимости
npm install

# 2) переменные окружения
cp .env.example .env        # при необходимости поправьте DATABASE_URL

# 3) база данных (если db/custom.db уже в репозитории — шаг можно пропустить)
npx prisma db push          # создать схему
node scripts/seed-products.mjs   # наполнить демо-товарами (12 шт.)

# 4) запуск
npm run dev                 # http://localhost:3000
```

Админка: `http://localhost:3000/admin/login` (пароль — `ADMIN_PASSCODE` из `.env`,
по умолчанию `dominant2026`).

## Что нужно заменить перед запуском «в бой»

- Телефон и часы работы — заглушки в `src/lib/site.ts`
- Пароль админки — `ADMIN_PASSCODE` в `.env`
